Office 365 — Modern Auth (OAuth 2.0)

Recommended for Microsoft 365 mailboxes: sign in once, no password stored, tokens refresh automatically. Takes a one-time, free app registration in your Microsoft account (~3 minutes) — follow the steps below.

{% if not o365_connected %}
One-time setup — get your two IDs from Microsoft
  1. Open the Microsoft Entra admin center (sign in as a Microsoft 365 admin) and go to Applications → App registrations → New registration.
  2. Name it anything (e.g. OpenPoolPro mail), choose “Accounts in this organizational directory only”, leave Redirect URI empty, and click Register.
  3. You land on the app's Overview page — copy the Application (client) ID and Directory (tenant) ID into the two fields below and hit Save Office 365 app details.
  4. Still in the app: Authentication → Advanced settings → set “Allow public client flows” to Yes → Save. (This is what lets the code-based sign-in below work.)
  5. API permissions → Add a permission → Microsoft Graph → Delegated permissions → search SMTP.Send → tick it → Add permissions. If a “Grant admin consent” button shows, click that too.
  6. One Exchange check: in the Exchange admin center → Recipients → Mailboxes → your sending mailbox → Email apps → make sure Authenticated SMTP is turned on. (Modern Auth replaces the password, not the SMTP protocol.)
  7. Back here: click Connect Office 365 below, enter the code Microsoft shows you at microsoft.com/devicelogin, and sign in as the mailbox you want to send from. This page updates by itself when you're done.
